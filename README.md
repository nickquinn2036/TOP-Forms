# Sign-Up Form | The Odin Project

A responsive sign-up page built from scratch as part of [The Odin Project's Intermediate HTML and CSS curriculum](https://theodinproject.com).

## Live Demo
🔗 **[View Live Site](//WIP)**

## Features
* **Semantic HTML5 Form:** Accessible `<label>` and `<input>` pairings, custom regex `pattern` validation for emails and phone numbers, and POST payload testing via `httpbin.org`.
* **Modern CSS Layout:** Two-column Flexbox page structure paired with a CSS Grid form layout, custom `@font-face` typography (`Norse`), and responsive `@media` queries for smaller screens.
* **Interactive Validation:** Visual `:focus` states, `:user-invalid` error borders, and real-time password-matching checks powered by vanilla JavaScript (`setCustomValidity`).
